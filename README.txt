For the most reliable experience on Android and iPhone, publish the ENTIRE extracted folder to GitHub Pages or another static website host, then open the published https link. Some mobile browsers restrict local file:// pages from loading neighbouring photos, audio and video files.

All media references in index.html are relative to this folder:
- assets/photos/
- assets/audio/
- assets/video/
- assets/background/

Background music: many browsers block autoplay with sound. If it does not start automatically, tap the Music button once. The music pauses while a personal video or voice note is playing and resumes after playback ends, subject to browser autoplay rules.
